App installieren

Installiere Aufgabentraining für das beste Erlebnis.

iPhone / iPad

1
Tippe auf den Teilen-Button.
2
Wähle "Zum Home-Bildschirm".
3
Tippe auf "Hinzufügen".

Android

1
Tippe auf das Dreipunkt-Menü.
2
Wähle "App installieren".

PC / Mac

1
Klicke auf das Installieren-Icon in der Adressleiste.
