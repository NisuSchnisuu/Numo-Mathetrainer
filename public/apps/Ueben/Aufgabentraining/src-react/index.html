App installieren

Installiere Aufgabentraining für das beste Erlebnis (Vollbild, Offline-Support).

🍎

Installation auf iPhone / iPad

1
Tippe unten auf den Teilen-Button.
2
Wähle "Zum Home-Bildschirm".
📱
3
Tippe oben rechts auf "Hinzufügen".
➕
🤖

Installation auf Android

1
Tippe auf das Menü (⋮) im Browser.
⋮
2
Wähle "App installieren".
📲
3
Bestätige die Installation.
✅
💻

Installation auf PC / Mac

1
Klicke auf das Installieren-Icon (⊕) in der Adressleiste.
2
Klicke im Dialog auf "Installieren".

App bereits installiert? Schließe diesen Tab und öffne die App!
